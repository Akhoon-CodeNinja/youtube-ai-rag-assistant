# My Project Contribution – DistilBERT Model

## 1. Dataset Cleaning and Preprocessing
Performed data cleaning and preprocessing on the SQuAD 2.0 dataset to prepare it for model training. This included handling the dataset, preparing question-answering data, and tokenization.

## 2. DistilBERT Model Training
Trained the DistilBERT (`distilbert-base-uncased`) model for the Question Answering task using the preprocessed SQuAD 2.0 dataset. Configured the training process and saved the trained model for further evaluation.

## 3. Final Testing and Evaluation
Conducted final testing and evaluation of the trained DistilBERT model to assess its question-answering performance. Evaluated its Exact Match (EM) and F1 scores and tested different no-answer thresholds to identify the model's best performance.

## 4. Contribution Summary
My contribution focused on dataset cleaning, preprocessing, DistilBERT model training, and final model testing and evaluation for the YouTube AI RAG Assistant project.
